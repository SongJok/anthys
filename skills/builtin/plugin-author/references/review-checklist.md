# 插件评审检查清单

## 清单与目录

- [ ] `plugin.json` 是合法 JSON，`schemaVersion` 为 `1`。
- [ ] `id` 匹配 `^[a-z0-9][a-z0-9.-]{1,63}$`，且与插件用途一致。
- [ ] `version` 是语义化版本，升级时严格递增。
- [ ] `engines.agent` 覆盖目标机器人版本。
- [ ] `trust` 为 `declarative`。
- [ ] `skills` 中每个目录都存在 `SKILL.md`，技能名不与内置/本地技能冲突。
- [ ] 技能正文符合 `skill-author` 规范，写操作有分级（普通写授权后直接执行、高危写 `/confirm`）和脱敏要求。

## MCP 节点

- [ ] 每个节点都有 `id`、`name`、`domain`、`transport`、`endpointOrCommand`。
- [ ] stdio 裸命令在白名单内；参数中不含明文密钥。
- [ ] 远程节点使用 HTTPS，鉴权头通过 `${ENV_VAR}` 注入。
- [ ] 只声明完成任务所需的节点；默认只读优先。
- [ ] 评估来源可信度、维护活跃度、网络访问范围和可写操作风险。
- [ ] 明确超时与结果截断，避免大结果拖垮上下文。

## 密钥与权限

- [ ] `secrets` 只声明变量名，值只放在 `.env`。
- [ ] 必需密钥缺失时安装应失败或插件保持禁用，并有清晰提示。
- [ ] 不在技能正文、README、日志或命令参数中泄露密钥。
- [ ] `permissions` 与真实需求一致，不夸大也不掩盖。

## 生命周期

- [ ] 全新安装成功，技能按命名空间出现。
- [ ] 缺密钥安装路径符合预期。
- [ ] 升级保留旧版本，可回滚。
- [ ] 停用后技能与 MCP 工具不再出现。
- [ ] 卸载不会删除手工配置或内置技能。
