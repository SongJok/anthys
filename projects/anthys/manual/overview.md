# 项目概览

## 定位

钉钉智能体（anthys）是一个常驻服务：通过钉钉 Stream 接收单聊、@ 与群内旁听消息，用 ReAct 循环调用企业 MCP、DWS、公网搜索、沙盒与内置工具，最终以 AI 卡片流式回复，并把过程写入审计轨迹与三层记忆。

## 核心能力

- 单聊 / @ 回答，群内未 @ 时按旁听策略决定是否主动回应。
- 工具调用：企业 MCP、钉钉 DWS、公网搜索、隔离沙盒、记忆、术语、个人提醒与定时任务。
- 管理控制台：模型、钉钉、MCP 策略、群策略、术语、保留策略、审计与技能/插件/项目。
- 扩展能力：技能（SKILL.md 渐进披露）、声明式插件（技能 + MCP 打包）、项目手册（确定性结构 + 人工条目）。

## 请求链路

1. Stream 推送消息后立即确认，再异步处理，避免重复投递。
2. 单聊与 @ 直接进入智能体；群内未 @ 先进入旁听缓冲，经规则过滤、防抢答等待与低温度模型判定后才唤醒智能体。
3. 智能体按人设、记忆、项目摘要与工具说明组装上下文，动态选择工具。
4. 状态角标、正文与工具轨迹实时写入同一张 AI 卡片。
5. 回答落库；后台压缩早期对话、抽取长期术语与职责画像。

## 关键入口

- 进程入口：`src/index.ts`（装配数据库、配置中心、Stream、管理 API、工具注册表与各服务）。
- 智能体循环：`src/harness/`（上下文组装、工具注册与 ReAct 执行）。
- 管理 API：`src/admin-api/`；控制台：`web-console/`。
- 数据库：Drizzle schema 位于 `src/db/`，建表用 `pnpm db:push`，扩展 SQL 用 `pnpm db:extend`。
- 部署资产：`deploy/`（systemd、Nginx、安装与部署脚本）。

## 边界

- 设计为单实例常驻；动态配置与群内冷却状态在进程内存中。
- 不对员工做静默写操作：写工具受确认策略与权限点约束。
- 真实钉钉、模型与企业 MCP 的连通性依赖部署环境网络与凭据。
