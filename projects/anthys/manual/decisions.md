# 决策记录

## 单实例动态配置，暂不做多租户

当前部署面向单机器人、单租户。动态配置、群内冷却与旁听缓冲都在单进程内；多实例需要额外的配置分发与广播机制，多机器人/多租户暂不实现。

## 运维目标是受控的自托管部署

生产环境采用自托管方式：常驻服务 + 反向代理 + 独立数据库，不使用托管容器平台。部署脚本保持幂等，升级走 `deploy/deploy.sh`。服务器地址、端口、绝对路径与凭据不进入仓库、手册与模型上下文。

## 项目手册以确定性事实为主

手册章节来自扫描器可复现的事实（目录、符号、配置变量名、脚本、部署文件），人工条目单独存储并审计；模型摘要只作为可选补充，不把生成内容当作事实。敏感文件不进入索引，手册只输出环境变量名。

## 项目检索保持混合打分

代码检索融合 FTS、trigram、路径/符号加权与可选向量；输出优先 `path:line` 与短片段，提示模型用 `project_read` 继续读取，避免一次塞入大段代码。

## MCP 偶发 TLS 失败按瞬时故障处理

企业 MCP 偶发 `ECONNRESET` / `fetch failed`，重试即可恢复，不按配置错误处理；工具等待与请求超时已放宽，但持续失败仍需查看节点与网络。

## DWS 受企业权限约束

DWS 只能访问已授权的组织与数据。跨组织群（如 sts 群）可能返回 `CrossOrgPermissionDenied`，此时需要人工在对应组织内操作，不能通过改代码绕过。

## 扩展能力默认逐步启用

技能、插件、项目作为扩展能力接入；插件只允许声明式清单，不执行代码。GitHub 工具通过 `GITHUB_ENABLED` 显式开启，未配置 token 时只能读公开仓库且受限流影响。
