# 常见问题

## 怎么更换模型？

控制台「大模型与人设」页修改并保存，配置进入动态配置中心，无需重启；也可改 `.env` 的 `LLM_*` 后重启作为默认值。

## 怎么新增企业 MCP？

在控制台「MCP 服务」页新增节点（地址、传输方式、请求头令牌），保存后测试连通性；工具会以 `mcp__<服务 id>__<工具名>` 注册，并按群/角色策略过滤。

## 为什么工具输出会被截断？

单次工具结果受节点 `maxResultChars` 与工具输出预算限制，防止上下文被大结果占满；需要完整数据时先用沙盒落盘再聚合，或缩小查询范围。

## 怎么新增技能？

内置技能放 `skills/builtin/<name>/SKILL.md`，本地技能放 `skills/local/`；也可通过控制台或 API 上传。前端 matter 描述触发条件，正文按需加载，避免常驻提示词膨胀。

## 怎么登记项目并让机器人理解代码？

控制台「项目手册」页登记项目（本地目录或 GitHub），发起同步生成快照；对话中机器人会按需调用 `project_search`、`project_read`、`project_map`、`project_symbol`。管理员可生成手册草稿并发布。

## 为什么手册里的配置只有变量名？

避免把密钥写入数据库、审计或模型上下文。手册只列出配置项名称与用途，值只存在于部署环境的 `.env`。

## GitHub 工具为什么不可用？

需要 `GITHUB_ENABLED=true`，并建议配置只读 `GITHUB_TOKEN`；代码搜索必须要有 token，公开仓库读取受匿名限流影响。

## 群里为什么有时不回复？

旁听会经过规则过滤、防抢答等待、低温度模型判定与置信度阈值；可在「群策略」页调整主题、冷却与阈值。

## 管理控制台打不开或接口 401？

确认已执行 `pnpm build`、Nginx 代理到 `8787`，且控制台填写的 Token 与服务端 `ADMIN_API_TOKEN` 一致。
