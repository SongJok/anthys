# 知识风险与待确认事项

- 本手册为 AI 对钉钉知识库的**初版梳理**，只深读了核心政策与产品文档，其余文档仅收录目录；需业务负责人审核。
- 部分文档标注已过期（如“CP 系统说明”），回答时不得作为现行规则。
- 政策中的阈值、金额、比例会调整，务必引用原文与日期。
- 薪酬、定级、提现、奖励等属于公司线上业务规则，可正常解答；仅“某个具体员工或队长的个人收入明细”不在群聊展示。
- 资质审核中的年龄、性别等限制未逐条收录，回答时请引导查阅原政策并向运营确认。
- 待补：统一指标口径表、各业务线负责人、实时数据对应的 MCP 工具清单。

## 文档间口径冲突与权限缺口（来自团队文件梳理）

- **手动关闭资质后的冷静期**：平台政策文档写 14 天内不可再次申请；研发 PRD《资质审核需求 03.16》写 7 日。回答时以平台政策为准，并提示向运营确认。
- **关厅后同板块入职免 CD**：PRD 中该条已被划线，视为已废止，不要作为现行规则。
- 研发 PRD 的数值（时薪、排档上限、奖励表）可能落后于线上，回答具体金额前提示“以当前政策与后台为准”。
- 团队文件中的「客服部」「兔玩&avatar项目」「测试团队」「乐园杀配置文件-线上环境」，当前登录账号经 API 无访问权限，未收录；管理员需授权后补充。
- 「海外团队项目文件夹/开发者等账号」可能包含账号凭据类内容，不收录，也不应由机器人回答。
