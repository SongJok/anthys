# 业务系统与角色地图

> 用于回答“这件事去哪查、找谁”。负责人姓名未收录，请管理员在 `owners` 中补齐。

| 事项 | 去哪看/系统 | 对口角色 |
| --- | --- | --- |
| 开厅申请、特殊队长录入、队长离职 | 点点后台（厅后台） | 厅管、板块运营 |
| 队长资质审核、打卡录音抽查、运营数据 | 织梦后台 | 板块运营、客服 |
| 巡查与处罚申诉 | 巡查记录、运营申诉渠道 | 板块运营、巡查 |
| 内容审核/封禁 | 客服审核后台、封禁判定标准 | 客服 |
| 需求工单与任务排期 | 需求工单系统（任务/工单 + 需求群） | 产品经理、各研发 Leader |
| 项目文档 | 钉钉知识库：知识沉淀、点点开黑平台政策、点点开黑产品知识库、点点开黑项目文档、兔小铲项目知识库、棋牌项目 | 各产品/项目负责人 |
| 实时数据（订单、流水、状态） | 企业 MCP 与数据服务（实时取数，不用文档里的旧数字） | 数据/研发 |
