# 业务术语与角色

> 来源：点点开黑平台政策 → 0-相关名词列表。以下为通用释义，术语库（Glossary）中的同名词条优先。

| 术语 | 含义 |
| --- | --- |
| 队长 / 歌手 | 通过玩游戏或唱歌与用户建联，平台最基本的服务单元；需具备导师资质并入职某个大厅排档 |
| 导师账号 / 导师资质 | 能入职大厅成为队长、主持的前提；需实名核验与水平/内容审核 |
| 风险队长 | 违规队长：套现、双开（多号）、诈骗等 |
| 主持 | 维护聊天室气氛，必须是队长，类似“DJ” |
| 陪档（嘉宾） | 与主持互动、辅助活跃气氛，可由队长或老板担任 |
| 老板 | 来平台玩的付费用户 |
| 厅管 | 大厅管理者，负责大厅流水、生态、队长招募/培训/排班、活动 |
| 队长管理 / 主持管理 | 协助厅管做招募、培训、排班 |
| 运营 | 平台线下工作人员，负责一个或多个厅的日常运营与活动；按板块划分（如狼人杀运营、游戏运营） |
| 巡查 | 特殊身份，不定期巡视大厅/车队，可踢人、禁言、封号、对队长扣薪 |
| 大厅（聊天室） | 商业主要场所，一个大厅即一个社区；分普通模板（1 主持麦 + 8 嘉宾麦）与活动模板（生日、加冕、拍卖、合唱、真心话大冒险等，每天一个、最长 3 小时） |
| 车队 / 歌房 / 桌 | 车队：队长与用户（侯爵及以上）的 1v1/多人游戏，多在非自研游戏大厅；歌房：歌手唱歌的小房间；桌：用户玩狼人杀/乐园杀的场所。均隶属大厅 |
| 假车 / 涉嫌假车 | 车队/歌房/桌内未正常游戏或唱歌（挂时长、放歌、开小号、买卖流水等）的违规行为 |
| 档期 / 排档 | 队长排班，按小时计；上档提前 30 分钟打卡 |
| 流水 | 大厅/队长的付费与礼物产生的营收口径，用于定级、预警、关厅（具体口径以政策文档为准） |
| 定级（入门/银牌/金牌…） | 按任务完成与流水对队长的等级划分，影响任职资格与待遇 |
| 豪华房活跃值 | 狼人杀豪华房的活跃指标，来源：桌内对局、钻石流水、金币流水 |
| 钻石 / 金币 | 平台虚拟货币；1 RMB = 10 钻 = 1000 金币（以豪华房说明文档口径） |
| 织梦后台 | 运营后台，展示队长信息、打卡录音抽查等 |
| 铲铲会 / 铲铲小助手 | 兔小铲内的任务体系与金铲铲辅助工具 |

> 待业务确认：流水、有效付费人数、支出占比等**指标口径定义**在政策文档中分散出现，建议补一页统一指标口径表并指定负责人。

## 经济与会员体系

> 来源：团队文件《陶乐科技聊天室运营人员工作守则 3.0》。

| 货币 | 兑换 | 获取与限制 |
| --- | --- | --- |
| 点点币 | 1 人民币 : 1 点点币 | 队长身份收到钻石礼物获得；仅排档队长身份可提现 |
| 钻石 | 1 人民币 : 10 钻石 | 充值、活动、收礼获得 |
| 紫晶 | 1 人民币 : 10 紫晶；1 钻石 : 1 紫晶 | 充值或钻石购买、活动、收礼获得；送紫晶礼物，对方收到紫晶，紫晶不能换钻石 |
| 金币 | 1 钻石 : 1 紫晶 : 100 金币；1 人民币 : 1000 金币 | 充值或用钻石/紫晶购买、做游戏任务/活动获得；不可逆向兑换 |

- **爵位（魅力值）**：长期有效，反映自注册以来消费实力，共 14 级：平民、骑士、男爵、子爵、伯爵、侯爵、公爵、亲王、国王、皇帝、玉帝、天帝、至尊、尊上；不同爵位有开宝箱数量、踢人卡、解封卡等权益。
- **赛季 VIP**：每 3 个月重置，V1–V6，反映最近一个赛季的消费实力，每赛季有主题与名称。
- 平台定位：以语音游戏（狼人杀）、游戏开黑（王者、LOL、和平、金铲铲等）和唱歌为基础玩法，以语音大厅为社区；每个大厅就是一个社区。
