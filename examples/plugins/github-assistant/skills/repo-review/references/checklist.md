# 评审检查清单

## 正确性

- [ ] 主路径是否符合需求，是否有遗漏分支
- [ ] 空值、越界、并发、重试是否处理
- [ ] 时间、时区、编码、排序是否稳定

## 安全

- [ ] 外部输入是否校验与转义
- [ ] 是否引入命令注入、路径穿越、SSRF、XSS
- [ ] 密钥是否只来自环境变量，是否可能进入日志

## 兼容与运维

- [ ] 数据库 / API / 配置是否向后兼容
- [ ] 失败时是否有明确错误与回滚路径
- [ ] 是否新增可观测性（日志、指标、审计）

## 测试

- [ ] 是否覆盖成功、失败与边界
- [ ] 是否存在依赖真实外部服务的不可重复测试
